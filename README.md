# Ecommerce Dashboard (Mini Store)

A dynamic e-commerce web application built with React and Vite that allows users to browse products, view detailed item pages, update local state, and manage a interactive shopping cart.

<img width="1917" height="906" alt="Mini Store Home" src="https://github.com/user-attachments/assets/800aa95b-e609-49e4-b732-6ec303ee8ac4" />

**Live Demo:** [View Project Live](https://ecommerce-dashboard-nu-smoky.vercel.app)

---

## Features

- **Browse Products:** Grid display of products dynamically fetched from the Fake Store API.
- **Product Details:** Dedicated routing (`/product/:id`) to display item details with synced local state.
- **Cart Management:** Real-time item count, quantity adjustment, and dynamic cart totals.
- **Data Persistence:** Preserves cart state and custom edits across sessions using `localStorage`.

---

## Tech Stack

- **Framework:** React + Vite
- **Routing:** React Router DOM
- **Styling:** Tailwind CSS
- **API:** Fake Store API
- **State & Storage:** React Hooks (`useState`, `useEffect`) & `LocalStorage`
